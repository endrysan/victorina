Обновление от 29 октября 2026 года.

Распакуйте архив целиком в одну папку. Откройте index.html в браузере.
index.html — главная страница.
miles-and-niles.html — Майлз и Найлз: 50 вопросов в случайном порядке, без уровней сложности, новые формулировки вопросов 8 и 13, блокнот с коровой и музыка Bookworm’s Game.
strashnye-skazki.html — три викторины по страшным сказкам.

Изображения, музыка, вопросы и код лежат в папках assets/, questions/ и shared/ рядом с HTML-файлами. Внешние загрузки для игры не нужны. Ссылка «На кофе» требует интернета.
Музыка может запускаться только после первого нажатия из-за ограничений браузера.
Прогресс хранится в браузере и автоматически не переносится с опубликованного сайта в скачанные файлы. Если хранилище недоступно, игра работает в памяти до закрытия страницы.
На телефоне используйте браузер, который поддерживает открытие локальных HTML. Встроенный просмотрщик файлов может не запускать JavaScript.
Для размещения сайта загрузите всё содержимое папки на хостинг (HTML-файлы и папки assets/, questions/, shared/).

Архив содержит последние изменения, даже если опубликованный сайт ещё не обновлён.
